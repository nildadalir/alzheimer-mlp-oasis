# Data

`raw/oasis_clinical.csv` is the OASIS longitudinal **clinical** table (not the MRI volumes) as used in the thesis. It was originally stored as `dataset1_orginal.csv`.

Columns: `Group`, `M/F`, `Age`, `EDUC`, `SES`, `MMSE`, `CDR`, `eTIV`, `nWBV`, `ASF`.

If you use this dataset in a paper, cite the OASIS project, for example:

> D. S. Marcus et al., “Open Access Series of Imaging Studies (OASIS): Cross-sectional MRI data in young, middle aged, nondemented, and demented older adults,” Journal of Cognitive Neuroscience, 2007.

Processed CSVs in `processed/` are generated by the MATLAB or Python pipelines and can be deleted and rebuilt.
