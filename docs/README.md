# Documents

| File | Description |
| --- | --- |
| `Bachelor_Thesis_English.docx` | Full English thesis |
| `original_thesis_persian.docx` | Original Persian submission |
| `figures/` | Figures used in the English thesis and the repository README |

Rebuild the English document after editing `scripts/build_english_thesis.py`:

```bash
python scripts/build_english_thesis.py
```

The methodology diagram used in the root README is regenerated with:

```bash
python scripts/generate_methodology_figure.py
```
